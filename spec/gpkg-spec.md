# BNG Service template: GeoPackage specification

> Generated by `python3 development/tools/gpkg_spec.py` from the template in [bng-metric-template](https://github.com/DEFRA/bng-metric-template). Do not edit by hand: change the template and regenerate.

Format `bng-service`, version `1.0`. A file in this format is a GeoPackage with the tables and columns below and the version record. The same content, for tools, is in [`spec/gpkg-spec.json`](https://github.com/DEFRA/bng-metric-template/blob/main/spec/gpkg-spec.json).

The service checks more than the format: how it reads each column, and what it refuses, is in the [template field mapping](https://github.com/DEFRA/bng-metric-backend/blob/main/data-dictionary/template-mapping.md).

## Version record

A file says which format it follows, and which version, in one row of the GeoPackage metadata extension, referenced to the whole GeoPackage. The BNG service refuses a file with none, with more than one, or with a version it does not support.

| Table | Column | Value |
| --- | --- | --- |
| gpkg_metadata | md_scope | `dataset` |
| gpkg_metadata | md_standard_uri | `tag:defra.gov.uk,2026:bng-metric/gpkg-format` |
| gpkg_metadata | mime_type | `application/json` |
| gpkg_metadata | metadata | `{"format": "bng-service", "version": "1.0"}` |
| gpkg_metadata_reference | reference_scope | `geopackage` |

## Lineage columns

Each post-intervention row names the baseline feature it continues.

| Column | Tables | What it holds |
| --- | --- | --- |
| `feature_uuid` | Baseline | A UUID naming the baseline feature. Each baseline feature of a table has its own. |
| `Parent Ref` | Post-Intervention | The Habitat Ref of the baseline feature the row continues, for people to read. |
| `parent_uuid` | Post-Intervention | The feature_uuid of the baseline feature the row continues, on the baseline table of the same habitat layer. Blank on a habitat created with no baseline parent. |
| `parent_geom` | Post-Intervention | The parent's shape when the row was copied from it, as WKT with coordinates rounded to 3 decimal places. It shows whether the baseline changed after the copy. |
